## ✨ Что умеет

| | |
|---|---|
| 🚀 **Xray внутри** | VLESS (Reality, TLS, XHTTP, WS, gRPC), VMess, Trojan, Shadowsocks, Hysteria2 |
| 🧱 **Обход белых списков** | Только с подпиской TanjiroCat VPN. Когда оператор включает белые списки, приложение само переключается на резервный канал и возвращается обратно, когда их снимут |
| 📥 **Подписки как в Happ** | Трафик, срок действия, объявления, автообновление, флаги серверов, ссылки `happ://add/…` |
| 🔄 **Принудительное обновление** | Провайдер может обновить подписку у всех пользователей одной командой |
| 🏦 **Банки и Госуслуги** | Российские приложения идут мимо VPN, а VPN может вставать на паузу, пока они открыты |
| 📊 **Пинг и автопереключение** | Проверка серверов одной кнопкой, зелёный кружок или миллисекунды |
| 🧩 **Виджет и шторка** | Растягиваемый виджет на рабочий стол и кнопка в быстрых настройках |
| 🌓 **Светлая и тёмная тема** | По умолчанию как в системе, с плавной сменой |
| 📶 **Раздача VPN** | Второй телефон может ходить через этот VPN по Wi-Fi или точке доступа |

## 💳 Подписка

Подписку TanjiroCat VPN с обходом белых списков можно купить у меня в Telegram: [@TanjiroCat](https://t.me/TanjiroCat).

**80 ₽ в месяц**, одна ссылка на одно устройство.

С подписками других VPN приложение тоже работает, но обход белых списков у них не включится.

## 📲 Установка

1. Скачайте **APK** из раздела [последней версии](https://github.com/TanjiroCat993/TanjiroCatVPN/releases/latest).
2. Откройте файл и разрешите установку из этого источника.
3. Если Play Защита попросит проверить приложение, можно отправить его на проверку.
4. Откройте приложение и вставьте ссылку на подписку, которую вам выдали.

> 🔑 Подписку выдаёт администратор. Одна ссылка работает на одном устройстве: для нового телефона попросите новую ссылку в [@TanjiroCat](https://t.me/TanjiroCat).

## 🔄 Обновления

Приложение само проверяет обновления при каждом открытии и показывает, что изменилось. Список всех версий есть прямо в приложении: **Настройки → История обновлений**, а также на странице [Releases](https://github.com/TanjiroCat993/TanjiroCatVPN/releases). Скачать можно только последнюю версию.

## 🔒 Безопасность

- Обновление устанавливается, только если оно подписано тем же ключом, что и приложение.
- Ссылки из других приложений и сайтов добавляются только после подтверждения.
- Подписки не могут открыть порты на телефоне.
- В этом репозитории нет исходного кода, ключей и ссылок на подписки.
